## Key Features
- **Interactive Grid**: 5x5 grid where users can:
  - Left-click cells to toggle obstacles
  - Right-click to set the start position
  - Double-click to set the goal position
- **Value Iteration**: Computes optimal policy with:
  - Discount factor γ = 0.9
  - Reward: +1 for reaching goal, -0.01 for other moves
  - Convergence threshold θ = 10^-4
- **Visualization**: Displays both value function V(s) and policy arrows for each cell
